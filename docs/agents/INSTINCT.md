# Instinct entry point moved

Agentic Skills, including every INSTINCT README/read me section. Find the
requesting person's private settings in their workspace. The maintained Git
entry point is `notion-agentic-skills/skills/underwriting/SKILL.md`.

it does not configure Notion, fetch private settings or execute a skill.
